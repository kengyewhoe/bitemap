# BiteMap frontend (static mock)

Mobile web screens from the Stitch HTML, wired with mock data. No real API yet — see [BACKEND.md](./BACKEND.md).

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173 → login → location → follow → map.

| Screen | File |
|---|---|
| Login | `login.html` |
| Location | `location.html` |
| Follow (onboarding) | `follow.html` |
| Map + nearby list | `home.html` |
| Saved | `saved.html` |
| Place | `place.html` |
| Good / Bad | `rate.html` |
| Influencers | `influencers.html` |
| Creator | `influencer.html` |
| Me | `me.html` |
